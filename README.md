# 🍽️ อิ่มใจ (ImJai) Cafe & Kitchen — AI Agent บน LINE OA

บอท **"น้องอิ่มใจ"** ตอบลูกค้าใน LINE, **รับออเดอร์ได้จริง**, เช็คว่าอาหารถึงไหนแล้ว
และเรียกแอดมินให้อัตโนมัติเมื่อเจอเรื่องเร่งด่วน — ทำงานบน **n8n 23 node**

## Google Sheets 5 แท็บ (ไฟล์เดียว)

**ฐานข้อมูล — คุณแก้เอง ระบบอ่านอย่างเดียว**

| แท็บ | คอลัมน์ | เนื้อหา |
|---|---|---|
| **StoreProfile** | key, value | ข้อมูลร้าน เวลาทำการ ที่ตั้ง นโยบาย (18 แถว) |
| **KnowledgeBase** | id, category, question, answer, tags | FAQ 15 ข้อ |
| **Products** | sku, name, category, price, description, allergens, is_available, promotion | เมนู 17 รายการ |

**ข้อมูลที่ระบบเขียนเอง**

| แท็บ | ใครเขียน | หน้าที่ |
|---|---|---|
| **Orders** | AI เขียนอัตโนมัติ | ออเดอร์จริง เลขที่ `ORD-yyyyMMdd-HHmmss` + เวลาที่รับได้ |
| **AIMemory** | AI เขียน / คุณติ๊กยืนยัน | คลังคำถาม-คำตอบ ยิ่งใช้ยิ่งแม่น |

> 💡 **แยกแท็บตามชนิดข้อมูลเพื่อลดความผิดพลาดของ AI** — ถ้ายัดทุกอย่างรวมตารางเดียว
> AI จะสับสนว่าแถวไหนคือเมนู แถวไหนคือ FAQ พอแยกแท็บแล้วแต่ละคอลัมน์มีความหมายชัดเจน
>
> ระบบยังแปลง `is_available` ให้ AI อ่านง่ายด้วย — `FALSE` จะถูกส่งเป็น **"⛔ หมด/ไม่พร้อมขาย"**
> ไม่ใช่คำว่า FALSE เฉย ๆ ที่ AI อาจตีความพลาด

### AIMemory ทำงานยังไง

1. ทุกบทสนทนาถูกบันทึกอัตโนมัติ พร้อม `verified = FALSE`
2. คุณเปิดชีตดู เห็นคำตอบไหนดี → ติ๊ก `verified` เป็น `TRUE`
3. ครั้งหน้า AI จะเห็นคำตอบนั้นเป็นตัวอย่าง แล้วตอบแนวเดียวกัน
4. เรื่องที่แอดมินตอบเอง ก็มาพิมพ์คำตอบใส่ชีตแล้วติ๊ก `TRUE` ได้ → ครั้งหน้าบอทตอบแทนได้เลย

ระบบเอาแค่ **30 แถวล่าสุดที่ verified = TRUE** เพื่อไม่ให้ context บวมและค่า API ไม่พุ่ง

## เริ่มใช้งาน (ประมาณ 40 นาที)

### 1. เตรียม n8n
ต้องเป็น n8n ที่เข้าถึงได้จากอินเทอร์เน็ตด้วย HTTPS และเวอร์ชัน **1.70 ขึ้นไป**
แนะนำ **n8n Cloud** (สมัครแล้วได้ URL เลย และเชื่อม Google Sheets ได้ด้วยปุ่มเดียว
ไม่ต้องไปตั้ง OAuth ใน Google Cloud Console)
ถ้าจะ self-host มีไฟล์ให้แล้วที่ `deploy/docker-compose.yml`

### 2. สร้าง Google Sheet
สร้าง Spreadsheet ใหม่ 1 ไฟล์ แล้วทำ **5 แท็บ ชื่อตรงเป๊ะ**:
`StoreProfile` · `KnowledgeBase` · `Products` · `Orders` · `AIMemory`

แต่ละแท็บ: **File → Import → Upload** เลือกไฟล์จากโฟลเดอร์ `data/`
→ Import location: **Replace current sheet** → Separator: **Comma**

| แท็บ | ไฟล์ |
|---|---|
| StoreProfile | `data/StoreProfile.csv` |
| KnowledgeBase | `data/KnowledgeBase.csv` |
| Products | `data/Products.csv` |
| Orders | `data/Orders.csv` |
| AIMemory | `data/AIMemory.csv` |

แล้วคัดลอก **Spreadsheet ID** จาก URL เก็บไว้
(`docs.google.com/spreadsheets/d/`**`ตรงนี้`**`/edit`)

### 3. สร้าง Discord Webhook
Discord → คลิกขวาที่ channel → **Edit Channel → Integrations → Webhooks → New Webhook** → **Copy Webhook URL**

ทดสอบว่าใช้ได้:
```bash
curl -X POST -H 'Content-Type: application/json' -d '{"content":"ทดสอบ ✅"}' '<Webhook URL>'
```

### 4. Import workflow
n8n → **⋯ → Import from File** → เลือก `workflow/imjai-line-ai-agent-lite.json`

### 5. แก้ 4 จุด

| แก้ที่ node | ใส่อะไร |
|---|---|
| node Google Sheets ทั้ง **7 ตัว** (`อ่านออเดอร์ของลูกค้า`, `อ่านข้อมูลร้าน (StoreProfile)`, `อ่าน FAQ (KnowledgeBase)`, `อ่านเมนู (Products)`, `อ่านคลังคำตอบที่ยืนยันแล้ว`, `🧾 บันทึกออเดอร์ลงชีต`, `บันทึกบทสนทนาลงคลัง`) | **Document** → เปลี่ยนเป็น *From list* แล้วเลือกไฟล์ Sheet ของคุณ (หรือวาง Spreadsheet ID) |
| `แตกข้อความจาก LINE` | บรรทัด `SECRET = '...'` → ใส่ **LINE Channel Secret** |
| `สร้าง log แจ้งแอดมิน` | บรรทัด `WEBHOOK = '...'` → ใส่ **Discord Webhook URL** |
| `สร้าง log ระบบพัง` | บรรทัด `WEBHOOK = '...'` → ใส่ **ตัวเดียวกัน** |

### 6. ผูก credential 3 ชุด

| credential | ตั้งชื่อว่า | ใช้ที่ |
|---|---|---|
| Google Sheets OAuth2 | `Google Sheets account` | node Google Sheets ทั้ง 7 ตัว |
| OpenAI | `OpenAi account` | `OpenAI Chat Model` |
| Header Auth — **Name:** `Authorization` **Value:** `Bearer <LINE Channel Access Token>` | `LINE Channel Access Token` | `ตอบลูกค้า (LINE)`, `ดึงชื่อลูกค้าจาก LINE` |

> ตั้งชื่อตรงตามนี้ n8n จะผูกให้ทุก node อัตโนมัติ

### 7. เปิดใช้งาน
1. **Save** → สับสวิตช์ **Active**
2. เปิด node `LINE Webhook` → คัดลอก **Production URL**
3. [LINE Developers Console](https://developers.line.biz/console/) → แท็บ Messaging API
   - **Webhook URL** = วาง URL → **Update** → **Verify** (ต้องขึ้น Success)
   - **Use webhook** เปิด ✅ · **Auto-reply messages** ปิด ❌
4. **⋯ → Settings → Error Workflow** → เลือก workflow นี้เอง (ให้แจ้ง Discord เวลาระบบพัง)

## ทดสอบ

แอด LINE OA เป็นเพื่อน แล้วพิมพ์ตามนี้

| พิมพ์ | ต้องได้ |
|---|---|
| `ร้านเปิดกี่โมง` | ตอบเวลาทำการทันที |
| `ลาเต้ราคาเท่าไหร่` | ตอบ 70 บาท |
| `ต้มยำกุ้งมีไหม` | บอกว่า **หมดวันนี้** + เสนอเมนูอื่น |
| `ขอสั่งลาเต้เย็น 1 แก้ว กับครัวซองต์ 1 ชิ้น รับที่ร้าน` | ถามชื่อ+เบอร์ → **ทวนรายการ + ยอดรวม 110 บาท** (ลดโปร 15) → ถามยืนยัน |
| `ยืนยันค่ะ` | ได้ **เลขออเดอร์ + เวลาที่รับได้** → เปิดชีต `Orders` ต้องเห็นแถวใหม่ |
| `ของถึงไหนแล้ว` | อ่านจากชีต `Orders` แล้วบอกสถานะ + เวลา |
| `ขอเงินคืนค่ะ` | รับเรื่อง ไม่รับปากคืนเงิน → **Discord เด้ง** |
| `ขอคุยกับแอดมิน` | **Discord เด้ง** พร้อมชื่อลูกค้าและคำถาม |

ทดสอบตรรกะโดยไม่ต้องต่อระบบจริง:
```bash
node tests/run-tests-lite.js     # 21 เคส
```

## กติกาที่ระบบบังคับไว้

บอท **ไม่มีอำนาจ** คืนเงิน / ยกเลิกออเดอร์ / ให้ส่วนลด — บังคับ 2 ชั้น

1. **System prompt** ห้ามรับปาก ให้ตอบว่าส่งเรื่องให้ทีมงานแล้ว พร้อมปิดท้ายด้วย `[[ADMIN]]`
2. **ไม่มี tool ให้ทำ** — tool เดียวที่บอทมีคือบันทึกออเดอร์ใหม่ ไม่มีทางแก้/ลบ/คืนเงินได้เลย

และมีตาข่ายกันพลาดชั้นที่ 2 ในโค้ด: ถ้าลูกค้าพิมพ์คำอย่าง *คืนเงิน / ยกเลิก / ส่วนลด / เส้นผม /
แพ้ / ฟ้อง / สคบ. / ด่วน / ขอแอดมิน* จะยิงเข้า Discord ทันที **แม้ AI ลืมใส่ `[[ADMIN]]`**

## ข้อควรรู้

| หัวข้อ | รายละเอียด |
|---|---|
| **AI คำนวณเงินเอง** | ยอดรวมมาจากการคำนวณของ AI ตามราคาในชีต ช่วงแรกควรเช็คชีต `Orders` เทียบกับที่ลูกค้าจ่ายจริงสัก 1-2 สัปดาห์ |
| **ไม่มีระบบตัดสต็อก** | ถ้าของหมดต้องไปแก้ `is_available` เป็น `FALSE` ในชีต `Products` เอง บอทจะรู้ทันทีในข้อความถัดไป |
| **ไม่มีระบบชำระเงิน** | ออเดอร์ที่บันทึกคือ "รับออเดอร์แล้ว" การเก็บเงินยังทำนอกระบบ |
| **ค่า OpenAI** | ส่งฐานข้อมูล ~50 แถวทุกข้อความ ตกราว 0.10–0.20 บาท/ข้อความ ถ้าอยากประหยัดเปลี่ยน model เป็น `gpt-4.1-mini` |
| **`sheetName` โหมด By Name** | ถ้า n8n ฟ้อง ให้เปิด node แล้วเลือกแท็บจาก dropdown ใหม่ |
