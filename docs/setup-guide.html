เปิดบัญชี n8n Cloud

n8n คือตัวที่รันระบบทั้งหมด ต้องเป็น n8n ที่เข้าถึงได้จากอินเทอร์เน็ต เพราะ LINE ต้องยิงข้อมูลเข้ามาหา ใช้ n8n Cloud จะได้ที่อยู่มาให้เลยไม่ต้องตั้งเซิร์ฟเวอร์เอง

  1. เข้า n8n.io กด Get started แล้วสมัครด้วยอีเมล

  3. จดที่อยู่ที่ได้มาไว้ หน้าตาประมาณ https://ชื่อคุณ.app.n8n.cloud

ช่องนี้จะเงียบสนิทเวลาปกติ จะดังก็ต่อเมื่อมีเรื่องด่วน ลูกค้าขอคุยกับคน หรือระบบมีปัญหา ไม่ต้องสร้างบอท ใช้แค่ที่อยู่สำหรับส่งข้อความอันเดียว

ลูกค้าได้ข้อความตอบซ้อนกัน 2 อัน

ระบบตอบอัตโนมัติของ LINE ยังเปิดอยู่ ไปปิดที่ LINE Console แท็บ Messaging API หัวข้อ Auto-reply messages

พอเว็บสั่งอาหารเสร็จ ทำอีก 2 อย่าง

ระบบเตรียมทางไว้ให้แล้ว ไม่ต้องรื้อ workflow ใหม่

  1. ให้เว็บเขียนออเดอร์ลงแท็บ Orders ตามคอลัมน์เดิม บอทจะตอบเรื่องสถานะออเดอร์ทาง LINE ได้ทันที
  2. เอาที่อยู่เว็บมาใส่บรรทัด ORDER_WEB_URL ในกล่อง ⚙️ ตั้งค่าระบบ บอทจะเริ่มส่ง QR code ให้ลูกค้าสแกนไปสั่งเองอัตโนมัติ
ถ้าเว็บส่ง line_user_id มาด้วย (ผ่าน LINE Login หรือ LIFF) บอทจะรู้เลยว่าออเดอร์ไหนเป็นของใคร ลูกค้าถามว่า “ของถึงไหนแล้ว” ได้โดยไม่ต้องบอกเลขออเดอร์
